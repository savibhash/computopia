## 🌌 About Computopia

**Computopia** is an encyclopedic cyber-academia platform and interactive computer science laboratory. It bridges the gap between abstract theoretical mathematics, physical silicon engineering, and practical software development. 

Whether you are studying the 5-stage RISC instruction pipeline, training a neural network from scratch via backpropagation, cracking Linux security wargames, or exploring quantum entanglement gates, Computopia provides a stunning, eye-friendly, distraction-free sanctuary.

---

## ⚡ Core Features

* **🚪 3D Gyroscopic Portal Entry:** An immersive 3D CSS astrolabe portal rotating in perspective space over kaleidoscope fractals.
* **⚙️ 10 Comprehensive CS Fundamentals:** Deep-dive textbook treatises covering Core Architecture, DSA, AI/ML, LLMs & Transformers, Cybersecurity, Robotics, Data Science, OS/Networks, and Quantum Theory—complete with mathematical proofs, SVG diagrams, and curated YouTube masterclasses.
* **👁️ Dual Eye-Comfort Modes:** Instantly toggle between *Soft Forest Slate Dark Mode* and *Warm Academic Sepia Paper Mode* for strain-free long study sessions.
* **🎞️ Interactive Visual Vault (Simulators):** Live, browser-native HTML5 Canvas simulators for Sorting algorithms, BFS Pathfinding grids, Conway's Game of Life cellular automata, and interactive logic gates.
* **💻 Split-Pane System Terminal & IDE:** A fully functional Linux shell simulator + browser code runner where you can execute JavaScript neural network and cryptography scripts live (`Ctrl + Enter`).
* **🔐 Zero-Trust Authentication Vault:** Secure login and registration backed by **Node.js, PostgreSQL, and MongoDB** with cryptographic password-strength entropy meters and a scrollable Personnel Dossier Drawer.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, Modern CSS3 (Glassmorphism, 3D Transforms, Custom Variables), Vanilla ES6+ JavaScript.
* **Backend:** Node.js, Express.js, JSON Web Tokens (JWT), Bcrypt.
* **Databases:** PostgreSQL (Relational users & profiles) + MongoDB / Mongoose (Telemetry & execution logs) with automated **Hybrid Disk Fallback**.
* **Visuals & Fonts:** Cinzel, Cormorant Garamond, Inter, JetBrains Mono, Dicebear Cyber Avatars, and Custom SVG Icons.
